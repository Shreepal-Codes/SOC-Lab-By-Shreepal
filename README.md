# SOC Investigation Lab

## Project Overview

A hands-on blue-team cybersecurity lab focused on developing foundational skills for a SOC Analyst Level 1 role.

The project uses Windows security logs and practical investigations to learn how defenders identify suspicious activity, examine evidence, assess alerts, and document incident response recommendations.

## Objectives

- Understand Windows security and system event logs.
- Investigate authentication and endpoint activity.
- Learn basic log querying with PowerShell.
- Explore Sysmon telemetry and network traffic analysis.
- Develop detection ideas and understand false positives.
- Document investigation timelines, evidence, conclusions, and recommended actions.
- Build a reproducible cybersecurity portfolio.

## Lab Environment

- Operating system: Windows 11 Home, 64-bit
- RAM: 16 GB
- Storage: NVMe SSD
- Workspace: `G:\SOC-Investigation-Lab`

## Tools

- Windows Event Viewer
- Windows PowerShell
- Visual Studio Code
- Git and GitHub

Additional tools will be introduced as the project progresses.

## Investigation Workflow

1. Define the scenario and investigation objective.
2. Identify relevant data sources.
3. Collect and examine available evidence.
4. Build a timeline and evaluate findings.
5. Consider alternative explanations and false positives.
6. Recommend appropriate response actions.
7. Document conclusions and limitations.
